# Kantonstour

One beer in every Swiss canton in three days, entirely by train — 16–18 October 2026.

Live page: https://nunigan.github.io/kantonstour/ — OpenStreetMap with the OpenRailwayMap overlay, real track geometry from SBB open data, both options (A: beer on board, B: all on the ground), per-leg SBB links, and a live layer that places every train currently running on the lines of the selected day (SBB timetable + reported delays via transport.opendata.ch).

`kantonstour.md` is the printable version. `tools/` regenerates everything.
